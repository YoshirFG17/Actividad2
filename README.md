# Proyecto HTML: Uso de Imágenes, Audio y Estilos

## Descripción
En esta actividad se desarrolló una página web utilizando HTML y estilos básicos. Se integraron imágenes y audio, además de aplicar estilos para mejorar la apariencia de la página.

---

## Estructura utilizada

### Encabezados
Se usaron:
- h1 para el título principal
- h2 para subtítulos

### Separadores
- hr para dividir el contenido

---

## Contenido multimedia

### Imágenes
Se utilizó la etiqueta:
<img src="imagen.jpg" alt="Descripción de la imagen">

### Audio
Se utilizó la etiqueta:
<audio controls>
  <source src="audio.mp3" type="audio/mpeg">
</audio>

---

## Estilos

Se aplicaron estilos básicos usando CSS:

### Estilo interno
```html
<style>
  body {
    background-color: #f0f0f0;
    font-family: Arial;
  }
  h1 {
    color: blue;
  }
</style>
